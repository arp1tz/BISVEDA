BISVEDA - VIDEO DEMO SCRIPT  (screen recording + voice-over + live phone call)
Length: 3 min 50 s maximum.  About 520 spoken words.
Each scene:  SCREEN = what you click / type   |   SAY = what you narrate.
All questions are also listed, in order, in DEMO_QUESTIONS.md.

==========================================================================================
BEFORE RECORDING
==========================================================================================
1. Restart everything so the NEW API keys load:  from C:\BISVEDA run   python scripts/boot.py
   (web http://localhost:3000 + voice bridge :8001). Wait for both "ready" lines.
2. Chrome, window 1440x900, zoom 100%, bookmarks bar hidden, notifications off.
   Tab 1: http://localhost:3000        Tab 2: http://localhost:3000/admin (already logged in).
3. Keep ready on the desktop:
     prototype/public/samples/hallmarked_gold.jpg
     example docs uploaded by employees/IS_2925_Specification_for_Industrial_Safety_Helmets_(Second_Revision).pdf
4. Copy the Form I details (Scene 4) to the clipboard.
5. Phone on speaker, ringer ON, next to the mic. Make one test call before recording.
6. One full dry run, then record. Don't run long test sessions on recording day (the free
   AI quota is about 60-80 answers a day).
7. In the edit, cut any waiting longer than 2 seconds.

SCENE 1 - OPENING  (0:00 - 0:12)
==========================================================================================
SCREEN: Home page. Move the cursor over the search box, the + and mic buttons, the language
        picker, and "Speak with BISVEDA on Call".
SAY:
"This is BISVEDA, an assistant for Indian Standards and BIS services. You can ask by text, photo,
voice or phone, in your own language, and every answer shows the exact clause it came from."

==========================================================================================
SCENE 2 - CITED ANSWER + HONEST REFUSAL  (0:12 - 0:45)
==========================================================================================
SCREEN: Type  Q1:  I make battery-operated toy cars for kids. Which standards apply?
SAY (while it works):
"I'm a toy maker. It understands the question, searches the official BIS documents, checks the
evidence, and only then writes."
SCREEN: Click [S1]. The source panel opens with the clause, page and "Open PDF".
SAY:
"It names IS 15644 for electric toys and IS 9873 for mechanical safety. Every sentence has a
source tag, and one click shows the exact clause and page."
SCREEN: Close the panel. Type  Q2:  domestic pressure cooker stainless steel standard
SAY:
"If the documents don't cover something, it says so, and points to the official BIS catalogue
instead of guessing."

==========================================================================================
SCENE 3 - HALLMARKING: PHOTO + CENTRE FINDER  (0:45 - 1:20)
==========================================================================================
SCREEN: "+ New chat". Click +, attach  hallmarked_gold.jpg , type
        Q3:  Is this hallmarked? What does the mark mean?

"And here are the nearest operative hallmarking centres, from the official Manak Online list."

==========================================================================================
IF SOMETHING GOES WRONG
==========================================================================================
- An answer looks short or odd: ask it again in a new chat, or cut it in the edit.
- A photo takes longer than 10 s: cut the wait in the edit.
- No ring within 20 s: check the boot window for the voice bridge / ngrok lines and retry.
  Last resort: record the call separately and splice it in.
- On the call, don't ask about the number of hallmark marks, cement, water or steel pipes
  (the phone agent doesn't read from the same cited documents as the web chat yet).
- Answers suddenly turn into raw text excerpts: the daily AI quota is used up. Record later.
